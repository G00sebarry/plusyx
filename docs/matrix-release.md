# Выпуск матрицы Plusyx

1. Перед публикацией сохранить ссылку на текущую рабочую версию в Vercel. Проверить, что целевой проект Supabase принадлежит рабочему Plusyx. Применить миграцию `supabase/migrations/20261125205033_create_private_life_matrices.sql` один раз. Она создаёт таблицу личных карт с доступом по идентификатору владельца. Обложки входят в снимок карты.
2. Для рабочей сборки установить в Vercel переменную `VITE_ENABLE_LIFE_MATRIX=true` для Production. Опубликовать подготовленную ветку обычной командой сборки проекта. Режим Vite `matrix-test` предназначен для отдельной тестовой базы.
3. В своём аккаунте открыть «Матрица», назвать ячейку и дождаться зелёной галочки. Обновить страницу и проверить название. Убедиться, что открываются доска, трекер и календарь. Для проверки обложек загрузить маленькую картинку, дождаться сохранения и открыть карту из другого браузера с тем же аккаунтом.

## Откат

Вернуть предыдущую рабочую публикацию в Vercel. Для следующей сборки отключить `VITE_ENABLE_LIFE_MATRIX`. Таблицу `life_matrices` сохранить: при повторном включении пользователи получат свои карты.
